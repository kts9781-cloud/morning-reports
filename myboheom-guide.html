증권은 편한 방식으로 등록

종이 보험증권은 카메라로 촬영하고, 휴대폰에 저장된 이미지는 사진에서 선택합니다. 보험사 앱이나 이메일로 받은 증권은 PDF 그대로 첨부할 수 있습니다.

  • 사진은 보험증권 전면이 모두 보이게 촬영
  • 암호가 설정된 PDF도 비밀번호와 함께 분석
  • 사진과 PDF를 함께 선택해 보완 가능

흩어진 보험을 한 목록으로

  • 등록 완료 상태를 카드에서 바로 확인
  • 월 총 보험료로 납입 규모 파악

  • 분야별 가입 건수와 보장 규모 확인
  • 보험 상세 화면으로 자연스럽게 이동

5분 사용설명서

앱 하단의 ‘마이보험 → AI 상담 → 청구 관리 → 설정’ 순서로 익히면 빠릅니다.

바로가기1. 보험 등록2. 분석 확인3. AI 상담4. 청구 준비5. 상태 관리

1. 보험증권 등록하기

‘마이보험’ 탭 오른쪽 아래의 + 버튼을 누르고 등록 방식을 선택합니다.

  1. 카메라: 보험증권 전체가 잘리지 않게 촬영합니다.
  2. 사진: 갤러리에 저장한 보험증권 이미지를 선택합니다.
  3. PDF: 보험사 앱이나 이메일에서 받은 증권 파일을 선택합니다.
  4. 선택한 파일을 확인하고 AI로 분석하기를 누릅니다.
암호 PDF는 비밀번호 표시가 나타납니다. 정확한 비밀번호를 입력해야 분석할 수 있습니다.

2. 분석 결과 확인하기

분석이 끝나면 보험 목록에서 상품명, 보험사, 월 보험료, 만기일을 확인합니다. 상단의 보장 분야별 현황은 현재 등록된 모든 보험을 합쳐 보여줍니다.

  1. 보험 카드를 눌러 상세 화면을 엽니다.
  2. 보장 항목과 금액을 확인합니다.
  3. 원본 증권과 다른 값이 있다면 보험사 또는 담당 설계사에게 확인합니다.
화면의 건수와 금액은 등록 시점의 분석 결과입니다. 계약 변경이나 갱신 후에는 최신 증권으로 다시 확인하세요.

3. AI 상담에 질문하기

‘AI 상담’ 탭에서 증상이나 사고 상황을 평소 말하듯 입력합니다.

  1. 예: “독감 걸렸어”, “화장실에서 넘어져 허리를 다쳤어”
  2. AI가 보유 보험 중 관련 가능 항목을 정리합니다.
  3. 예상 금액과 필요 서류를 확인합니다.
  4. 필요하면 ‘청구 접수하기’ 또는 ‘설계사에게 보내기’로 이어갑니다.
AI 답변은 참고용입니다. 보장 확정과 지급 결정은 보험사의 약관 검토와 심사를 따릅니다.

4. 청구 서류 준비하기

청구 상세 화면의 ‘필요 서류’에서 각 항목 오른쪽 카메라 버튼을 누릅니다.

  1. 진단서·진료확인서, 처방전, 영수증 등 안내된 서류를 발급받습니다.
  2. 문서의 네 모서리와 글자가 선명하게 보이도록 촬영합니다.
  3. 촬영이 끝난 항목은 완료 표시와 진행률로 확인합니다.
  4. 보험사 또는 담당 설계사에게 제출하기 전 내용을 다시 확인합니다.

5. 청구 진행 상태 관리하기

‘청구 관리’ 탭에서 각 청구 건의 상태와 실제 수령액을 기록합니다.

준비중서류발급중청구완료입금완료
  1. 청구 카드를 열어 현재 단계를 선택합니다.
  2. 보험금이 입금되면 ‘입금완료’로 변경합니다.
  3. 실제 수령액을 입력하면 누적 수령 금액에 반영됩니다.
목록의 날짜·금액·건수는 앱 기능을 보여주는 촬영 예시이며, 모든 사용자에게 동일하게 표시되는 값이 아닙니다.

보험과 의료 문서는 민감한 정보를 포함합니다. 등록 전 파일을 확인하고, 결과는 최종 판단이 아닌 준비 도구로 활용하세요.

분석 결과는 참고용

마이보험은 보장 내용을 이해하고 청구 준비를 돕습니다. 실제 보장 여부, 면책 조건, 지급 금액은 담당 설계사 또는 보험사에 직접 확인하세요.

문서는 필요한 경우에만 공유

신분증, 통장 사본, 진단서 등에는 개인정보가 포함됩니다. 수신인을 확인한 뒤 보험사나 담당 설계사에게 전달하세요.

보험증권 분석이 오래 걸려요.

파일 크기와 페이지 수, 네트워크 상태에 따라 시간이 달라질 수 있습니다. 앱을 종료하지 말고 진행률을 확인하세요. 오래 멈춘 경우 네트워크를 확인한 뒤 파일을 다시 선택해 주세요.

PDF 옆에 ‘비밀번호’가 표시돼요.

암호화된 보험증권입니다. 보험사 앱이나 이메일에서 안내받은 문서 비밀번호를 입력해야 내용을 분석할 수 있습니다.

AI 예상금액과 실제 지급액이 달라요.

AI 예상금액은 등록된 증권의 분석 결과를 바탕으로 한 참고치입니다. 사고 경위, 치료 내용, 면책·감액 조건과 보험사 심사에 따라 실제 지급액이 달라질 수 있습니다.

보험이 갱신되거나 변경됐어요.

최신 보험증권을 다시 등록해 현재 계약 내용을 확인하세요. 오래된 분석 결과만으로 보장 여부를 판단하지 않는 것이 안전합니다.
