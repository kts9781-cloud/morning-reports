00 · Correction

이전 문서는 구현 보고서에 가까웠습니다

방향은 맞았지만 Claude Code가 실제 수정에 들어갈 때 여러 결정을 다시 내려야 했습니다. 아래 모호점을 이번 버전에서 모두 고정했습니다.

범위가 큼

P0·P1·P2가 한 문서에 섞여 어디까지 한 번에 구현할지 불명확했습니다.

계약 부족

null, false, 체중 제한, 가방·유모차 조합의 정확한 우선순위가 부족했습니다.

실행 단위 부족

파일별 변경, 실패 테스트, RPC 반환값, 중단 지점이 상세하지 않았습니다.

v2 해결: 구현 범위와 비대상, 24개 판정 케이스, SQL/RPC 계약, UI draft/commit 상태, 정확한 명령과 Claude Code 프롬프트를 포함합니다.

체중→크기 추천

export function suggestDogSize(weightKg: number): DogSize | null { if (!Number.isFinite(weightKg) || weightKg <= 0) return null; if (weightKg < 10) return 'small'; if (weightKg < 25) return 'medium'; return 'large'; }

정책 3상태

허용형

true=가능 · false=불가 · null=모름
pet/indoor/terrace/size/stroller

요구형

true=필수 · false=필수 아님 · null=모름
carrier/leash/diaper/barking

우선순위

최대 허용 체중 → 크기 허용 → 일반 동반 가능
