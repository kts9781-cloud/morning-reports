가입과 업종 설정이 화면을 결정합니다

1

회원가입 후 이메일 확인

2

‘어떤 분이신가요?’에서 유형 선택

실제 신고 형태와 가장 가까운 항목을 고릅니다. 개인사업자는 업종과 현금·카드 매출 형태, 법인은 업종과 직원 수, 임대사업자는 임대 유형을 추가로 입력합니다.

3

홈: 오늘 확인할 것부터

  • 숫자를 누르면 관련 상세 내역을 확인합니다.
  • 내부 이체나 카드대금 정산은 손익에서 중복 집계되지 않도록 구분됩니다.
  • 금액이 예상과 다르면 전표의 날짜·입출금 방향·분류부터 확인합니다.

전표: 월말 정리의 중심

월을 바꾸고 전체·미분류·입금·출금·증빙 확인 필요 등의 필터로 빠진 거래를 찾습니다.

  • 빨간 배지는 아직 분류하지 않은 전표 수입니다.
  • 계정과목, 설명, 메모, 카드·통장 연결을 수정합니다.
  • 삭제 전에는 중복 입력인지 실제 거래인지 한 번 더 확인합니다.
03 · RECORD

거래와 영수증을 넣는 3가지 방법

한 가지 방식만 고집할 필요가 없습니다. 말로 입력하고, 영수증은 촬영하고, 증빙이 없는 해외 구독 등은 수동으로 보완하세요.

💬

자연어 거래 입력

“국민은행으로 매출 30만원 들어왔어”처럼 날짜·금액·수단·용도를 말하듯 입력합니다.

📷

영수증 AI 분석

촬영 또는 갤러리 선택 후 가맹점·금액·날짜·비용처리 가능성·계정과목을 검토합니다.

✍️

누락 결제 직접 추가

영수증 없는 해외 SaaS·API·카드 명세서 거래를 직접 입력하고 카드와 연결합니다.

A

자연어 거래 입력

홈의 거래 입력 버튼또는거래 입력 화면

좋은 입력: “7월 3일 신한은행으로 거래처 대금 55만원 입금”처럼 날짜, 수단, 금액, 이유를 함께 씁니다. AI가 만든 전표는 저장 전에 입금/출금, 금액, 계정과목을 확인하세요.

같은 거래를 통장 입력과 영수증 저장으로 두 번 만들지 않도록 기존 전표 연결 여부를 확인하세요.
B

영수증 촬영·분석·저장

홈›영수증 비용처리›카메라 촬영 / 갤러리 선택

영수증 전체가 밝고 반듯하게 보이도록 촬영합니다. 분석 후 가맹점, 날짜, 총액, 카드, 비용 목적, 부가세 공제 상태를 직접 확인한 다음 저장합니다.

AI 판정은 참고용입니다. ‘가능’으로 표시돼도 실제 업무 관련성과 적격증빙 요건은 사용자가 확인해야 합니다. 틀린 정보는 저장 전에 수정하거나 메모로 보완하세요.
C

영수증 없는 결제 보완

영수증 비용처리›+ 영수증 없이 누락 결제 추가

해외 구독·API·명세서 결제처럼 영수증이 없을 때 날짜, 원화 금액, 가맹점, 카드, 용도를 입력합니다. 증빙이 부족한 거래는 메모에 근거를 남기고 세무사와 확인하세요.

말하듯 입력해도, 저장은 숫자로 확인

AI는 입력을 돕지만 최종 전표는 사용자의 장부가 됩니다. 저장 버튼을 누르기 전에 날짜, 금액, 입출금 방향, 결제수단, 계정과목을 확인하세요.

카드 탭: 월별 사용액과 사람별 내역

월을 바꿔 총 사용액, 주요 사용처, 직원·카드별 금액을 봅니다. 카드대금 출금은 비용을 새로 만드는 거래가 아니라 이미 입력된 카드 지출의 정산인지 확인하세요.

최신 버전에서 ‘PDF로 누락 결제 찾기’가 보이는 경우: 카드사 이용내역 PDF를 선택하고, 중복 의심 행을 제외한 누락 후보만 검토해 일괄 등록할 수 있습니다. PDF 비밀번호는 해당 분석에만 사용되고 장부에 저장하지 않습니다. 메뉴가 없으면 앱을 최신 버전으로 업데이트해 주세요.

대표·관리자: 14일짜리 1회용 코드 만들기

설정›직원 및 초대코드 관리
  • 직원·관리자·세무 담당자 중 역할을 고릅니다.

  • 사용한 코드나 더 이상 필요 없는 코드는 비활성화합니다.
  • 직원별 이번 달 영수증 제출 건수와 금액을 확인합니다.
1

직원: 회원가입 또는 로그인

초대 메시지의 앱을 설치하고 본인 계정으로 로그인합니다.

2

‘초대코드로 회사에 합류하기’에서 관리자가 보낸 코드를 입력합니다.

3

직원 제출 모드에서는 본인 카드 등록, 영수증 촬영·제출, 내가 올린 제출 내역 확인을 사용합니다. 제출 자료는 관리자가 검토합니다.

초대코드는 회사 자료 접근 권한과 연결됩니다. 공개 채팅방에 올리지 말고 대상 직원에게만 전달하세요.
07 · EXPORT

세무자료 보내기는 설정에서 시작합니다

세무사 이메일을 먼저 등록한 뒤, 자료가 존재하는 월만 선택해 이메일 또는 휴대폰 공유 기능으로 보냅니다.

1

세무사 정보 등록

설정›세무사 관리›세무사 등록

이름, 이메일, 사용하는 회계 프로그램(선택)을 입력합니다. 이메일 주소는 전송 전 다시 확인하세요.

2

‘세무자료 보내기’에서 월 선택

거래·급여·영수증 중 저장 자료가 있는 월이 표시됩니다. 여러 달을 선택할 수 있으며, 미분류 전표가 있다면 먼저 정리하는 것이 좋습니다.

3

TROUBLESHOOTING

막힐 때 가장 먼저 확인할 것

세무자료 보내기에 선택할 월이 나오지 않아요.
해당 월에 저장된 거래, 급여, 영수증이 있는지 확인하세요. 자료가 하나도 없으면 보낼 월이 표시되지 않습니다. 전표의 거래 날짜가 원하는 월로 입력됐는지도 확인해 주세요.
홈과 카드 리포트의 금액이 달라요.
조회 기간과 집계 기준이 다를 수 있습니다. 내부 이체, 카드대금 정산, 미분류 전표, 직원 카드, 취소·환불 거래를 차례로 확인하세요. 카드 결제 자체와 카드대금 출금을 둘 다 비용으로 입력하면 중복될 수 있습니다.
AI가 영수증을 잘못 읽었어요.
영수증 전체가 밝고 반듯하게 나오도록 다시 촬영하세요. 저장 전 날짜·가맹점·금액·카드·비용 목적을 직접 확인하고, 애매한 부분은 메모로 보완하세요. AI 결과를 그대로 저장할 의무는 없습니다.
카메라나 알림이 작동하지 않아요.
iPhone/Android의 설정에서 기장비서AI 카메라·사진·알림 권한이 허용됐는지 확인하세요. 알림은 앱 안의 토글뿐 아니라 기기 권한도 켜져 있어야 합니다.
직원이 회사 전체 장부를 볼 수 없어요.
정상입니다. 직원 역할은 본인 카드 등록과 영수증 제출 중심이며 전체 장부는 대표·관리자 권한에서 관리합니다. 더 넓은 권한이 필요하면 새 초대코드를 만들 때 역할을 신중히 선택하세요.
PDF 카드 명세서 가져오기 메뉴가 없어요.
이 기능은 지원 버전에서 순차 제공됩니다. 먼저 App Store 또는 Google Play에서 최신 버전으로 업데이트하세요. 업데이트 후에도 보이지 않으면 카드 탭과 등록 카드 여부를 확인하거나 설정의 ‘관리자에게 문의하기’로 알려주세요.
구독을 복원하거나 해지하고 싶어요.
같은 Apple ID 또는 Google 계정으로 로그인한 뒤 설정의 구독 영역에서 복원을 시도하세요. 해지는 iOS ‘설정 → Apple ID → 구독’ 또는 Google Play ‘결제 및 구독’에서 직접 처리합니다.
오류나 기능 문의는 어디에 하나요?
앱의 ‘설정 → 문의·피드백 → 관리자에게 문의하기’에서 오류 신고, 기능 제안, 사용 문의를 보낼 수 있습니다. 문제가 난 화면, 시각, 하려던 작업을 함께 적으면 확인이 빨라집니다.
