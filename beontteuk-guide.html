나만의 잠긴 공간.

번뜩은 단순히 메모를 쌓는 앱이 아닙니다. 생각과 사진을 빠르게 기록하고, 필요할 때 다시 찾으며, 보여주고 싶지 않은 내용은 한 번 더 숨길 수 있도록 설계했습니다.

01 · CAPTURE

떠오른 순간 바로 기록

제목은 선택입니다. 본문부터 적어도 되고, 사진만 먼저 보관해도 됩니다.

02 · FIND

검색하고 다시 발견

제목과 본문을 검색하고, 목록·그리드 보기로 생각을 빠르게 훑습니다.

03 · PROTECT

PIN과 생체 인증

6자리 금고 PIN으로 잠그고, 지원 기기에서는 Face ID 또는 지문으로 편리하게 엽니다.

30초 빠른 시작가입 또는 로그인 → 6자리 PIN 설정 → 홈의 ＋ 버튼 → 내용 작성 → 저장
Step by step

처음부터 차근차근
사용하는 방법

앱의 실제 화면과 현재 기능을 기준으로 정리했습니다. 화면 속 아이디어와 개수는 촬영 당시의 예시입니다.

1

계정을 만들거나 로그인합니다

이메일과 6자 이상의 비밀번호로 가입하거나 Google·Apple 계정을 이용합니다. 이메일 인증 안내가 표시되면 받은 편지함의 링크를 누른 뒤 로그인하세요.

계정 비밀번호와 금고 PIN은 서로 다른 역할입니다. 로그인 정보와 6자리 금고 PIN을 각각 안전하게 관리하세요.
2

6자리 금고 PIN을 설정합니다

처음 로그인하면 새 PIN을 입력하고 같은 번호를 한 번 더 입력해 확인합니다. 이후 앱 금고와 보호 영역을 여는 데 사용됩니다.

중요: PIN을 잊으면 저장된 암호화 데이터를 복구할 수 없습니다. 기억할 수 있으면서 추측하기 어려운 번호를 사용하세요.

PIN 설정 순서

6자리 입력 → 동일 PIN 재입력 → 금고 생성 완료

3

새 아이디어를 저장합니다

홈 오른쪽 아래의 ＋ 버튼을 누릅니다. 제목은 선택이고, 본문에 아이디어를 적은 다음 오른쪽 위 저장을 누릅니다. 제목·본문·기존 사진 중 하나 이상이 있어야 저장할 수 있습니다.

4

홈에서 찾고 정리합니다

검색창은 제목과 본문을 함께 검색합니다. 오른쪽 보기 전환 버튼으로 목록 또는 그리드를 선택하고, 아래로 당겨 새로고침할 수 있습니다. 화면 내용을 두 번 탭하면 카드 미리보기를 가리거나 다시 표시합니다.

5

아이디어를 열어 활용합니다

카드를 누르면 전체 내용을 봅니다. 상단의 아이콘으로 숨기기·수정·삭제를 실행하고, 아래의 전체 복사로 제목과 본문을 복사합니다. 삭제는 되돌릴 수 없으므로 확인 후 진행하세요.

6

사진첩에 안전하게 보관합니다

하단 사진첩 탭을 열면 생체 인증 또는 금고 PIN을 한 번 더 확인합니다. ＋ 버튼으로 사진을 추가하면 저장 전에 기기에서 암호화됩니다. 썸네일은 처음에 가려지며 화면을 두 번 탭해 표시할 수 있습니다.

  • 한 번에 최대 5장 선택
  • 사진을 눌러 전체 화면으로 보고 좌우로 이동
  • 길게 눌러 선택 모드 진입 후 여러 장 삭제

사진첩 보호 흐름

추가 인증 → 가려진 썸네일 → 두 번 탭해 보기 → 필요할 때 다시 가리기

7

보안과 계정을 관리합니다

설정에서 생체 인증 잠금 해제를 켜고, 즉시 금고를 잠그거나 로그아웃할 수 있습니다. 개인정보처리방침과 계정 삭제 안내도 여기서 확인합니다.

“계정과 모든 데이터 삭제”는 아이디어와 사진을 영구 삭제하며 복구할 수 없습니다.

번뜩은 앱 안의 잠금과 화면 가림을 통해 일상적인 엿보기를 줄이고, 저장 전 기기에서 콘텐츠를 암호화하는 흐름을 사용합니다.

01 금고 PIN

앱의 암호화 금고를 여는 6자리 PIN입니다. 로그인 비밀번호와 별개입니다.

02 생체 인증

기기가 지원하면 Face ID 또는 지문으로 빠르게 잠금 해제할 수 있습니다.

03 미리보기 가림

홈 카드와 사진첩 썸네일을 가려 주변에서 내용을 바로 알아보기 어렵게 합니다.

04 숨긴 아이디어

민감한 아이디어를 일반 홈에서 제외하고 추가 인증 뒤의 별도 공간에서 확인합니다.

꼭 기억하세요

금고 PIN은 서버에서 대신 찾아주는 복구 비밀번호가 아닙니다. PIN을 잊으면 암호화된 데이터를 복구할 수 없습니다. 삭제한 아이디어·사진과 계정 데이터도 되돌릴 수 없습니다.

공용 기기에서는 사용 후 로그아웃하고, 다른 사람이 볼 수 있는 상황에서는 “지금 잠그기”를 사용하세요.

FAQ

자주 묻는 질문

로그인 비밀번호와 금고 PIN은 같은 것인가요?

아닙니다. 로그인 비밀번호는 계정 인증용이고, 6자리 금고 PIN은 암호화된 개인 금고를 여는 용도입니다.

PIN을 잊어버리면 어떻게 하나요?

암호화된 기존 데이터는 복구할 수 없습니다. 이 때문에 PIN을 설정할 때 별도로 안전하게 기억해 두는 것이 중요합니다.

아이디어 내용이 갑자기 가려졌어요.

홈과 사진첩은 사생활 보호를 위해 포커스를 다시 받을 때 미리보기를 가릴 수 있습니다. 콘텐츠 영역을 빠르게 두 번 탭해 표시 상태를 전환하세요.

숨기기와 가리기는 무엇이 다른가요?

가리기는 현재 화면에서 미리보기만 덮는 기능입니다. 숨기기는 해당 아이디어를 일반 홈에서 빼고 추가 인증이 필요한 “숨긴 아이디어” 공간으로 이동합니다.

사진 접근 권한을 거부했어요.

기기 설정에서 번뜩의 사진 접근 권한을 허용한 뒤 다시 사진첩의 ＋ 버튼을 누르세요. 앱은 카메라·마이크 권한을 요구하지 않습니다.

아이디어나 계정을 삭제한 뒤 복구할 수 있나요?

복구할 수 없습니다. 특히 설정의 “계정과 모든 데이터 삭제”는 암호화된 아이디어와 사진을 포함한 전체 데이터를 영구 삭제합니다.
